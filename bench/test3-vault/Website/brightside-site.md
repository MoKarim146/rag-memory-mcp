# Brightside Studio website

The website of Brightside Studio, the design agency where Ines and Kofi work. Not related to TrailMate.

- Built with Next.js, hosted on Vercel, content in markdown files in the repo.
- Contact form posts to Formspree. Spam has increased since September; plan is to add a honeypot field.
- Domain renews on 2 February 2027.
- Analytics: none. The agency does not want a cookie banner.
