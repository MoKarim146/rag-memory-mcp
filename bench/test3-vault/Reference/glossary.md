# Glossary

- Region: an area whose map and trails can be downloaded for offline use.
- Offline pack: the downloaded map tiles and trail data for one region.
- Route: what a hiker records. A trail is what we publish; a route is the user's own track.
- Plus: the paid subscription, TrailMate Plus.
- Emergency share: sending a live location link to up to three contacts.
- Route file: what the app calls a GPX file in the interface.
